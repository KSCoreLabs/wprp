SETUP GUIDE

Up & Running in 60 Seconds

Four simple steps from install to catching your first red packet automatically.

01
♿

Enable Accessibility Service

Go to Settings → Accessibility → WPRP and enable the service. This grants the gesture dispatch permission needed for lightning-fast tapping.

Settings → Accessibility → WPRP → Enable
02
🪟

Allow Floating Window

Grant the Display Over Other Apps permission. This enables the control widget to float over WePlay without interrupting your session.

Settings → Apps → WPRP → Display Over Other Apps
03
🚀

Start the Auto-Tracker

Open WPRP, choose your engine mode (Vision / Accessibility / Dual), set your confidence threshold, and tap Start — the floating widget appears.

WPRP App → Select Mode → Start
04
🎉

Open WePlay & Collect!

Switch to WePlay, join any voice room, tap ▶ Play on the floating overlay — and watch WPRP auto-collect every red packet at superhuman speed.

WePlay → Voice Room → ▶ Play on Widget

Terms, Privacy & Permissions

🔒

Privacy Policy

No Data Collection: WPRP does not collect, store, transmit, or share any personal data, usage statistics, or device information.

On-Device Only: All screen frame analysis is performed entirely in RAM and immediately discarded. No images, frames, or screenshots are ever written to storage.

No Network Access: WPRP requires zero internet permissions. It operates entirely offline and makes no outbound network requests of any kind.

No Accounts: No sign-in, no accounts, no email, no phone number required.

♿

Accessibility Service

Purpose: The Accessibility Service is used exclusively to dispatch programmatic tap gestures on the WePlay application UI.

Scope: WPRP only interacts with WePlay app windows. It does not read content from other applications, access notifications, or observe keystrokes.

Revocable: You can disable the Accessibility Service at any time from Settings. WPRP will immediately stop functioning.

📽️

MediaProjection

Purpose: MediaProjection is used to capture live screen frames for real-time red packet detection (Vision Engine mode only).

RAM-Only Processing: Captured frames are analyzed using computer vision algorithms in RAM. Frames are never encoded, compressed, or written to any storage location.

User-Controlled: MediaProjection starts only when you tap "Start" and stops immediately when you tap "Stop" or close the app.
